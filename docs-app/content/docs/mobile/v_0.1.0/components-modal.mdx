# Modal

`Modal` используйте для подтверждений и сценариев, где нужно сфокусировать пользователя на одном действии.

## Базовый пример

```tsx
import React, { useState } from 'react';
import { Button, Modal, Typography } from '@plainerV/ui-native';
import { ButtonVariant } from '@plainerV/ui-core';

export function RemoveProjectModalExample() {
  const [isModalOpen, setIsModalOpen] = useState(false);

  return (
    <>
      <Button variant={ButtonVariant.DANGER} onPress={() => setIsModalOpen(true)}>
        Удалить проект
      </Button>

      <Modal
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        title="Удалить проект?"
        description="Это действие нельзя отменить."
      >
        <Typography variant="body">Подтвердите удаление проекта.</Typography>
      </Modal>
    </>
  );
}
```

## Основные входные параметры

- `isOpen: boolean` — состояние открытия модального окна;
- `onClose: () => void` — обработчик закрытия;
- `title?: string` — заголовок;
- `description?: string` — описание;
- `children?: React.ReactNode` — контент модального окна.

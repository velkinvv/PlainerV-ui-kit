# Toast

`Toast` используйте для короткой обратной связи после действий пользователя.

## Базовый пример

```tsx
import React from 'react';
import { Button, useToast } from '@plainerV/ui-native';
import { ButtonVariant } from '@plainerV/ui-core';

export function SaveWithToastButton() {
  const { showToast } = useToast();

  const handleSavePress = () => {
    showToast('Изменения сохранены', 'success', 'Готово');
  };

  return (
    <Button variant={ButtonVariant.PRIMARY} onPress={handleSavePress}>
      Сохранить
    </Button>
  );
}
```

## Основные входные параметры

- `message: string` — основной текст уведомления;
- `type?: 'success' | 'error' | 'warning' | 'info' | 'neutral'` — тип уведомления;
- `title?: string` — заголовок;
- `duration?: number` — длительность показа в миллисекундах.

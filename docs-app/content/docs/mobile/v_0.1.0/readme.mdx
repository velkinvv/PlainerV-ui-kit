# @plainerV/mobile

React Native версия UI Kit @plainerV/ui с сохранением всех стилей и функционала.

## 📦 Структура проекта

```
mobile/
├── packages/
│   ├── ui-themes/     # Общие темы и типы
│   ├── ui-core/       # Общая бизнес-логика
│   └── ui-native/     # React Native компоненты
├── package.json
└── README.md
```

## 🚀 Установка

```bash
cd mobile
npm install
```

## 📚 Пакеты

### @plainerV/ui-themes
Общие темы (light/dark) и типы, используемые как web, так и native версиями.

### @plainerV/ui-core
Общая бизнес-логика: обработчики, утилиты, типы.

### @plainerV/ui-native
React Native компоненты с адаптированными стилями и анимациями.

## 🔧 Разработка

```bash
# Сборка всех пакетов
npm run build

# Сборка конкретного пакета
npm run build:themes
npm run build:core
npm run build:native

# Разработка
npm run dev

# Проверка типов
npm run type-check

# Линтинг
npm run lint

# Тесты
npm run test
```

## 📖 Использование

```typescript
import { Button, Input, ThemeProvider } from '@plainerV/ui-native';
import { lightTheme, darkTheme } from '@plainerV/ui-themes';

function App() {
  return (
    <ThemeProvider theme={lightTheme}>
      <Button variant="primary">Нажми меня</Button>
      <Input label="Email" placeholder="Введите email" />
    </ThemeProvider>
  );
}
```

# Architecture

Mobile-часть состоит из трёх пакетов, которые разделяют тему, бизнес-логику и UI.

## Пакеты

- `@plainerV/ui-themes` — тема, токены, цветовые схемы;
- `@plainerV/ui-core` — типы, перечисления, общая логика;
- `@plainerV/ui-native` — React Native компоненты.

## Зависимости между пакетами

- `ui-themes` не зависит от `ui-native`;
- `ui-core` использует `ui-themes`;
- `ui-native` использует `ui-core` и `ui-themes`.

## Практические рекомендации по слоям

- компоненты и стили экрана размещайте в отдельном модуле фичи;
- валидацию форм выносите в отдельные хелперы или handlers;
- enums и типы из `ui-core` используйте как единый источник правды для пропсов.

## Когда менять слой

- меняем `ui-themes`, если нужно изменить дизайн-токены;
- меняем `ui-core`, если требуется общий тип/логика, переиспользуемые в web и native;
- меняем `ui-native`, если нужно поведение/визуал конкретного RN-компонента.

## Основные входные параметры

- `ThemeProvider.initialTheme` — объект стартовой темы для mobile-дерева;
- enums из `@plainerV/ui-core` (`ButtonVariant`, `Size` и другие) — единый контракт пропсов;
- типы из `@plainerV/ui-themes` — единая типизация токенов для web/mobile.

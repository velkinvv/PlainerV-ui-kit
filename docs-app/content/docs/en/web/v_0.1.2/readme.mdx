# @velkinvv/plainerv

![npm version](https://img.shields.io/npm/v/@velkinvv/plainerv)
![license](https://img.shields.io/npm/l/@velkinvv/plainerv)
![npm downloads](https://img.shields.io/npm/dm/@velkinvv/plainerv)

Modern library of UI components with support for theming and TypeScript.

## 🚀 Opportunities

- **🎨 Full theming** - Supports light and dark themes with automatic switching
- **🎯 TypeScript** - Full typing of all components and props
- **📱 Adaptive design** - Components adapted to all devices
- **⚡ Performance** - Optimized components with minimal bundle
- **🎭 Animations** - Smooth animations with Framer Motion
- **🔧 Customization** - Flexible customization through props and themes
- **📚 Storybook** - Interactive documentation and playground

## 📦 Installation

```bash
npm i @velkinvv/plainerv
```

## 📦 Import styles and fonts

For the library to work correctly, you need to import styles:

```tsx
// Import styles (includes fonts)import '@velkinvv/plainerv/styles';
// orimport '@velkinvv/plainerv/dist/styles.css';
```

Fonts are automatically included when importing styles.

## 🎨 Theming

The library supports full theming with automatic switching between light and dark themes:

```tsx
import { ThemeProvider, useTheme, ThemeToggle } from '@velkinvv/plainerv';

function App() {
  return (
    <ThemeProvider>
      <div>
        <ThemeToggle />
        <YourApp />
      </div>
    </ThemeProvider>
  );
}
```

### Using Themes in Components

```tsx
import { useTheme } from '@velkinvv/plainerv';

function MyComponent() {
  const { mode, toggle } = useTheme();

  return (
    <div>
      <p>Current topic:{mode}</p>
      <button onClick={toggle}>Switch topic</button>
    </div>
  );
}
```

## 🎯 Components

### Main UI components

- **Button** - Buttons with different options and states
- **ButtonGroup** - Group `Button` / `IconButton` (`orientation`, `attached`, `fullWidth`, `aria-label`)
- **Link** - Link `mode="text"` (styled `<a>`) or `mode="button"` (same `Button` with `href`)
- **Input** - Input fields with validation and various types
- **TextArea** - Multiline input field (states, tooltips, counter at `maxLength`, `Form`)
- **FileInput** - File selection (hidden `input[type=file]`, trigger, label, clear action, `Form`)
- **Card** - Cards for content
- **Modal** - Modal windows
- **Drawer** - Drawer panel (portal, overlay like `Modal`, `placement`, focus trap)
- **Sheet** - Sheet panel as `Drawer`, default bottom (`placement="bottom"`), `safe-area` for bottom edge
- **Icon** - Icons (Lucide React + Plainer icons)
- **ThemeToggle** - Theme switch

### Forms

- **Form** - `<form>` wrapper and context for `Input` / `TextArea` / `FileInput` / `Select` (the `form` attribute on fields)
- **Checkbox** - Checkboxes
- **Switch** - Switch (track + slider, signature, error)
- **Radio** - Radio buttons
- **DateInput** - Date input fields
- **Calendar** - month grid (locale `locale`, `weekStartsOn`, `minDate` / `maxDate`, month/year dropdown in `Dropdown`, modes `headerMode`, control `value` / `visibleMonth`)
- **TimeInput** - Time input fields
- **Select** - `mode="select"`: panel like `Dropdown` (search, multi-select) + hidden `select` for forms; `mode="native"` - native list

### Navigation

- **Sidemenu** - Side navigation bar
- **Tabs** - Tabs
- **Breadcrumb** - “Breadcrumbs” (`nav` + `ol`, `aria-current`, separator, `Size`)
- **Stepper** - Layout navigation steps: `variant="compact"` ("N/M" ring, header, subheader, `onBack`) or `variant="linear"` (circles, "Step N" labels, connectors); `appearance` / theme, `fullWidth`
- **Pagination** - Page numbers with breaks "...", back/forward arrows, controlled and uncontrolled modes (`totalPages`, `page` / `defaultPage`, `onPageChange`, `siblingCount`, `showPrevNext`, `size`)
- **Menu** — vertical navigation (`Menu` + `MenuItem`), badge, collapsed; for the toolbar on top of the canvas - **FloatingMenu**
- **FloatingMenu** - floating toolbar at the bottom/edge of the screen (`FloatingMenuPlacement`), dragging (`draggable`, `dragSource`, `DragHandle`), groups `FloatingMenu.Group` (`variant: inset`), separator `Divider`, item `GroupItem` (icon, `active`, `tooltip`, nested `Menu` via `dropdownContent`, opening by `dropdownTrigger`: click hover)
- **Dropdown** - Dropdown menus

```tsx
import { ThemeProvider, Pagination } from '@velkinvv/plainerv';

<ThemeProvider>
  <Pagination
    totalPages={24}
    page={currentPage}
    onPageChange={setCurrentPage}
    siblingCount={1}
    showPrevNext
    ariaLabel="List pages"
  />
</ThemeProvider>
```

### Data display

- **Badge** - Badges and tags
- **Avatar** - User avatars
- **Progress** - Progress indicators
- **Spinner** - Loading spinners
- **Skeleton** - Loading skeletons

### Feedback

- **Tooltip** - Hints
- **Hint** - Advanced hints
- **Toast** + **ToastProvider** / **useToast** - Notification stack (portal in `body`, types success/error/warning/info)
- **Snackbar** + **SnackbarProvider** / **useSnackbar** - Compact bars at the bottom of the screen, optional action and timer (portal in `body`)
- **Modal** - Modal windows
- **Drawer** - Drawer panel (overlay, Escape, sides `left` | `right` | `top` | `bottom`)
- **Sheet** - The same props as `Drawer`; default - bottom sheet and height `min(50vh, 560px)`

#### Toast and Snackbar in the application

Both stacks are rendered into `document.body`. You need a **`ThemeProvider`** (theme for styled components) and a notification provider. It is convenient to put them in the root; The nesting order is arbitrary if both providers wrap the same tree.

```tsx
import { ThemeProvider, ToastProvider, SnackbarProvider } from '@velkinvv/plainerv';

function Root() {
  return (
    <ThemeProvider>
      <ToastProvider placement="top-right">
        <SnackbarProvider placement="bottom-center">
          <App />
        </SnackbarProvider>
      </ToastProvider>
    </ThemeProvider>
  );
}
```

**Storybook:** `Hooks/useToast`, `Hooks/useSnackbar`, `Components/Feedback/Toast`, `Components/Feedback/Snackbar`, `Components/Navigation/Pagination`, `Components/Navigation/FloatingMenu`, `Components/Buttons/ButtonGroup`.
- **Accordion** - Accordions

## 🎭 Animations

All components use Framer Motion for smooth animations:

```tsx
import { Button } from '@velkinvv/plainerv';

<Button
  variant="primary"
  whileHover={{ scale: 1.05 }}
  whileTap={{ scale: 0.95 }}
>
  Animated button</Button>
```

## 📝 Examples of use

### Simple form

```tsx
import { Input, Button, Card } from '@velkinvv/plainerv';

function LoginForm() {
  return (
    <Card>
      <Input
        label="Email"
        type="email"
        placeholder="Enter email"
        required
      />
      <Input
        label="Password"
        type="password"
        placeholder="Enter your password"
        required
      />
      <Button variant="primary" fullWidth>
        Login      </Button>
    </Card>
  );
}
```

### Navigation with Sidemenu

```tsx
import { Sidemenu, ThemeToggle } from '@velkinvv/plainerv';

function AppLayout() {
  const sidemenuItems = [
    { id: 'home', label: 'Home', icon: 'Home', active: true },
    { id: 'profile', label: 'Profile', icon: 'User' },
    { id: 'settings', label: 'Settings', icon: 'Settings' },
  ];

  return (
    <div style={{ display: 'flex' }}>
      <Sidemenu items={sidemenuItems} />
      <main>
        <header>
          <ThemeToggle />
        </header>
        <YourContent />
      </main>
    </div>
  );
}
```

## 🌳 Tree-shaking

The library supports tree-shaking thanks to the `sideEffects: false` setting. This means that by importing only the required components, unused code will be excluded from the final bundle.

```tsx
// ✅ Good - only Button is imported`nimport { Button } from '@velkinvv/plainerv';

// ❌ Bad - the entire package is imported`nimport * as UI from '@velkinvv/plainerv';
```

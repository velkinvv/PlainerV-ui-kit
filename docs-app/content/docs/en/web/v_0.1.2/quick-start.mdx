# Quick Start

This page is a short start for `v0.1.2` to quickly connect the library and get a working UI.

## 1) Installation

```bash
npm i @velkinvv/plainerv
```

## 2) Configure the theme at the application root

```tsx
import { ThemeProvider } from '@velkinvv/plainerv';

type ApplicationRootProps = {
  children: React.ReactNode;
};

export function ApplicationRoot({ children }: ApplicationRootProps) {
  return <ThemeProvider>{children}</ThemeProvider>;
}
```

## 3) First working screen example

```tsx
import { Button, Card, Input } from '@velkinvv/plainerv';

export function QuickStartDemo() {
  return (
    <Card>
      <Input label="Email" placeholder="team@plainerv.dev" />
      <Button variant="primary">Save</Button>
    </Card>
  );
}
```

## Key component parameters

- `ThemeProvider.children: React.ReactNode` - application tree within the theme;
- `Input.label?: React.ReactNode` — field label;
- `Input.placeholder?: string` — hint text in empty state;
- `Button.variant?: ButtonVariant` — visual variant of the button;
- `Button.children?: React.ReactNode` - button content.

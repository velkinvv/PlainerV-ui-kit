# Feedback

Group of components for notifications and action status messages.

**Components:** `Tooltip`, `Hint`, `Toast`, `ToastProvider`, `Snackbar`, `SnackbarProvider`.

**Hooks:** `useToast`, `useSnackbar` (providers required near the app root).

Reference: [Components reference](/docs/en/web/v_0.1.3/components-catalog). Guide: [Toast + Snackbar](/docs/en/web/v_0.1.3/components-toast-snackbar).

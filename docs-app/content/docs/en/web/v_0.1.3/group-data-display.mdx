# Data Display

Group of components for tabular and structured data rendering.

**Visual / status:** `Badge`, `Tag`, `Pill`, `Avatar`, `AvatarGroup`, `Progress`, `Spinner`, `Skeleton`, `Divider`, `Slider`, `RangeSlider`, `Calendar`, `DateRollerPicker`, `Icon`, `ThemeToggle`.

**Tables:** `TableContainer`, `TableContainerScroll`, `Table`, `TableHead`, `TableBody`, `TableFooter`, `TableRow`, `TableCell`, `TablePagination`, `TableSortLabel`, `TableSortChevronIcon`, helpers, `DataGrid`, `ColumnFilterPanel`.

Full import list: [Components reference](/docs/en/web/v_0.1.3/components-catalog). Guide: [Table + DataGrid](/docs/en/web/v_0.1.3/components-table-datagrid).

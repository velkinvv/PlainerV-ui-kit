# Button

`Button` is the basic action component. Below is the minimum set of working scripts for `v0.1.3`.

## Basic options

```tsx
import { Button } from '@velkinvv/plainerv';

export function ButtonVariantsDemo() {
  return (
    <section>
      <Button variant="primary">Primary</Button>
      <Button variant="secondary">Secondary</Button>
      <Button variant="ghost">Ghost</Button>
      <Button variant="danger">Danger</Button>
    </section>
  );
}
```

## Main input parameters

- `variant?: ButtonVariant` — visual style of the button (`primary`, `secondary`, `ghost`, `danger` and others);
- `size?: Size` — button size;
- `loading?: boolean` — loading state;
- `disabled?: boolean` — blocking interaction;
- `fullWidth?: boolean` — stretching to the width of the container;
- `iconStart?: React.ReactNode` — icon at the beginning of the button;
- `iconEnd?: React.ReactNode` - the icon at the end of the button.

## Full description of Button props

### Button-specific

- `variant?: ButtonVariant` — visual design option;
- `size?: Size` — button size;
- `iconStart?: React.ReactNode` — icon to the left of the text;
- `iconEnd?: React.ReactNode` — icon to the right of the text;
- `showTooltip?: boolean` — enable tooltip for the button;
- `tooltipText?: string` — tooltip text;
- `href?: string` - if set, the button is rendered as `<a>`;
- `target?: React.HTMLAttributeAnchorTarget` - transition target for `href`;
- `rel?: string` — the `rel` value for the link;
- `download?: string | boolean` — download attribute for the link.

### Basic button props (BaseButtonProps)

- `loading?: boolean` — loading state;
- `disabled?: boolean` — blocking interaction;
- `fullWidth?: boolean` — stretching to the width of the container;
- `rounded?: boolean` — rounded shape of the button.

### Native HTML props

`Button` extends `React.ButtonHTMLAttributes<HTMLButtonElement>` so it supports standard attributes:

- `type?: 'button' | 'submit' | 'reset'`
- `onClick?: React.MouseEventHandler<HTMLButtonElement>`
- `aria-*`, `data-*`, `name`, `value`, `tabIndex` and other standard fields.

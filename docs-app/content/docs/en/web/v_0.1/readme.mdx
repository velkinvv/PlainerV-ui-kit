# @velkinvv/plainerv

![npm version](https://img.shields.io/npm/v/@velkinvv/plainerv)
![license](https://img.shields.io/npm/l/@velkinvv/plainerv)
![npm downloads](https://img.shields.io/npm/dm/@velkinvv/plainerv)

Modern library of UI components with support for theming and TypeScript.

## 🚀 Opportunities

- **🎨 Full theming** - Supports light and dark themes with automatic switching
- **🎯 TypeScript** - Full typing of all components and props
- **📱 Adaptive design** - Components adapted to all devices
- **⚡ Performance** - Optimized components with minimal bundle
- **🎭 Animations** - Smooth animations with Framer Motion
- **🔧 Customization** - Flexible customization through props and themes
- **📚 Storybook** - Interactive documentation and playground

## 📦 Installation

```bash
npm i @velkinvv/plainerv
```

## 📦 Import styles and fonts

For the library to work correctly, you need to import styles:

```tsx
// Import styles (includes fonts)import '@velkinvv/plainerv/styles';
// orimport '@velkinvv/plainerv/dist/styles.css';
```

Fonts are automatically included when importing styles.

## 🎨 Theming

The library supports full theming with automatic switching between light and dark themes:

```tsx
import { ThemeProvider, useTheme, ThemeToggle } from '@velkinvv/plainerv';

function App() {
  return (
    <ThemeProvider>
      <div>
        <ThemeToggle />
        <YourApp />
      </div>
    </ThemeProvider>
  );
}
```

### Using Themes in Components

```tsx
import { useTheme } from '@velkinvv/plainerv';

function MyComponent() {
  const { mode, toggle } = useTheme();

  return (
    <div>
      <p>Current topic:{mode}</p>
      <button onClick={toggle}>Switch topic</button>
    </div>
  );
}
```

## 🎭 Animations

All components use Framer Motion for smooth animations:

```tsx
import { Button } from '@velkinvv/plainerv';

<Button
  variant="primary"
  whileHover={{ scale: 1.05 }}
  whileTap={{ scale: 0.95 }}
>
  Animated button</Button>
```

## 📝 Examples of use

### Simple form

```tsx
import { Input, Button, Card } from '@velkinvv/plainerv';

function LoginForm() {
  return (
    <Card>
      <Input
        label="Email"
        type="email"
        placeholder="Enter email"
        required
      />
      <Input
        label="Password"
        type="password"
        placeholder="Enter your password"
        required
      />
      <Button variant="primary" fullWidth>
        Login      </Button>
    </Card>
  );
}
```

### Navigation with Sidemenu

```tsx
import { Sidemenu, ThemeToggle } from '@velkinvv/plainerv';

function AppLayout() {
  const sidemenuItems = [
    { id: 'home', label: 'Home', icon: 'Home', active: true },
    { id: 'profile', label: 'Profile', icon: 'User' },
    { id: 'settings', label: 'Settings', icon: 'Settings' },
  ];

  return (
    <div style={{ display: 'flex' }}>
      <Sidemenu items={sidemenuItems} />
      <main>
        <header>
          <ThemeToggle />
        </header>
        <YourContent />
      </main>
    </div>
  );
}
```

## 🌳 Tree-shaking

The library supports tree-shaking thanks to the `sideEffects: false` setting. This means that by importing only the required components, unused code will be excluded from the final bundle.

```tsx
// ✅ Good - only Button is imported`nimport { Button } from '@velkinvv/plainerv';

// ❌ Bad - the entire package is imported`nimport * as UI from '@velkinvv/plainerv';
```

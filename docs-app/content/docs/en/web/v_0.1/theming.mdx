# Theming

The theme is managed through `ThemeProvider` and `useTheme`.

## Example

```tsx
import { Button, useTheme } from '@velkinvv/plainerv';

export function ThemeControls() {
  const { mode, toggle } = useTheme();

  return (
    <section>
      <p>Current mode:{mode}</p>
      <Button variant="secondary" onClick={toggle}>
        Switch topic      </Button>
    </section>
  );
}
```

## Parameters and values

- `ThemeProvider.children: React.ReactNode` - tree of components inside the theme;
- `useTheme().mode` — current mode;
- `useTheme().toggle()` - mode switching.

# Installation and configuration instructions

## 📋 Prerequisites

- Node.js >= 16.0.0
- npm >= 8.0.0
- React Native CLI (for developing React Native components)

## 🚀 Installation

### 1. Installation dependencies

```bash
cd mobile
npm install
```

### 2. Setting up workspace

The project uses npm workspaces. All packages will be installed automatically.

### 3. Building packages

```bash
# Build all packagesnpm run build

# Or building a specific packagenpm run build:themes
npm run build:core
npm run build:native
```

## 📦 Package structure

### @plainerV/ui-themes
Common themes and types. Does not require additional dependencies.

### @plainerV/ui-core
General business logic. Depends on:
- `@plainerV/ui-themes`
- `dayjs`

### @plainerV/ui-native
React Native components. Depends on:
- `@plainerV/ui-themes`
- `@plainerV/ui-core`
- `react-native`
- `react-native-reanimated`
- `react-native-gesture-handler`
- `@react-native-async-storage/async-storage`
- `styled-components`

## 🔧 Development


## ⚠️ Important notes

- All packages use the workspace protocol for local dependencies
- When a dependent package changes, you need to rebuild the dependent packages
- To work with React Native components, you need to configure the React Native environment

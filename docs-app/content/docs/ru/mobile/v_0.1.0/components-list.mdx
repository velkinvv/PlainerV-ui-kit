# Список компонентов @plainerV/ui-native

## ✅ Реализованные компоненты (20)

### Формы и ввод данных
1. **Button** - Кнопки с 8 вариантами, 5 размерами, состояниями загрузки
2. **Input** - Поля ввода с валидацией, ошибками, размерами, multiline
3. **Checkbox** - Чекбоксы с метками и ошибками
4. **RadioButton** - Радиокнопки
5. **RadioGroup** - Группы радиокнопок
6. **Switch** - Переключатели с анимациями
7. **Dropdown** - Выпадающие списки с поиском и множественным выбором

10. **Badge** - Бейджи с 12 вариантами, dot режимом
11. **Divider** - Разделители (горизонтальные и вертикальные)

### Индикаторы и загрузка
12. **Spinner** - Спиннеры загрузки (4 варианта)
13. **Skeleton** - Скелетоны загрузки (4 варианта)
14. **Progress** - Индикаторы прогресса (линейный и круговой)

### Модальные окна
15. **Modal** - Модальные окна с полной функциональностью

### Пользовательские компоненты
16. **Avatar** - Аватары пользователей с генерацией инициалов
17. **Tooltip** - Всплывающие подсказки
18. **Toast** - Уведомления с интеграцией useToast
19. **Tabs** - Вкладки (горизонтальные и вертикальные)
20. **Accordion** - Аккордеон с поддержкой множественного открытия

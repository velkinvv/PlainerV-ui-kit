# Справочник компонентов (v0.3.1)

Ниже перечислены **все сущности**, реэкспортируемые из entrypoint пакета `@velkinvv/plainerv` (см. `src/components/ui/index.ts`, `src/hooks/index.ts`, `src/handlers/index.ts`). Типы и перечисления — из `@velkinvv/plainerv` (модуль `types/ui`, `types/theme` и др.).

Детальные сценарии и интерактив — в **Storybook** (`cd web && npm run storybook`). Темы и токены — раздел [Theming](/docs/web/v_0.3.1/theming).

---

## Кнопки и ссылки

| Экспорт | Назначение |
|--------|------------|
| `Button` | Основная кнопка действия (`ButtonVariant`, `Size`, иконки, `href` как ссылка). |
| `ButtonGroup` | Группа кнопок: ориентация, `attached`, режим переключателя. |
| `MultiButton` | Split-кнопка: основное действие + шеврон с меню (`DropMenu`). |
| `SegmentedControl` | Сегментированный контрол: `appearance`, `selectionMode` single/multiple, `options` или `Item`. |
| `IconButton` | Кнопка только с иконкой. |
| `Link`, `LinkMode` | Ссылка: текстовая или в виде кнопки (`mode`). |

```tsx
import {
  Button,
  ButtonGroup,
  MultiButton,
  SegmentedControl,
  IconButton,
  Link,
  LinkMode,
} from '@velkinvv/plainerv';
```

## Ввод и формы

| Экспорт | Назначение |
|--------|------------|
| `Input` | Однострочное поле, маски, ошибки, счётчик, tooltip/hint. |
| `TextArea` | Многострочный ввод. |
| `FileInput` | Загрузка файлов (`FileInputLayout`). |
| `Select` | Выпадающий/нативный выбор (`SelectOption`, режимы `select` / `searchSelect` / `native`); при multiple — токены на **Chip**. |
| `MultiInput` | Несколько значений в одном поле (токены на атоме **Chip**). |
| `SliderInput` | Число + встроенный слайдер в рамке **Input**; `range` — пара «от / до» (как **DateInput**). Типы `SliderInputSingleProps`, `SliderInputRangeProps`. |
| `Form`, `HiddenUsernameField` | Обёртка формы и скрытое поле для менеджеров паролей. |
| `DateInput` | Дата (и диапазон). |
| `TimeInput` | Время (и диапазон). |
| `Checkbox`, `CheckboxGroup` | Чекбоксы и группа. |
| `Switch` | Переключатель. |
| `RadioButton`, `RadioButtonGroup` | Радиокнопки и группа опций. |

```tsx
import {
  Input,
  TextArea,
  FileInput,
  Select,
  MultiInput,
  SliderInput,
  Form,
  DateInput,
  TimeInput,
  Checkbox,
  CheckboxGroup,
  Switch,
  RadioButton,
  RadioButtonGroup,
  type SliderInputSingleProps,
  type SliderInputRangeProps,
} from '@velkinvv/plainerv';
```

## Поверхности, сетка и всплывающие слои

| Экспорт | Назначение |
|--------|------------|
| `Card` | Карточка контента. |
| `Modal` | Модальное окно (портал, оверлей, фокус). |
| `Drawer`, `DrawerPlacement` | Выдвижная панель. |
| `Sheet`, `SheetPlacement` | Нижний/боковой «лист» (общий контракт с Drawer). |
| `Grid`, `GridItem`, `GridMode` | CSS Grid (`GridProps`, `GridBreakpoint`, `GridItemProps`). |
| `Dropdown` | Выпадающая панель с триггером. |
| `DropMenu` | Фасад над `Dropdown`: гибкий триггер, алиасы `isVisible` / `onSelectItem`. |
| `Popover`, `PopoverVariant` | Панель произвольного контента у триггера (в т.ч. `inline`). |

```tsx
import {
  Card,
  Modal,
  Drawer,
  Sheet,
  Grid,
  GridItem,
  GridMode,
  Dropdown,
  DropMenu,
  Popover,
} from '@velkinvv/plainerv';
```

## Навигация и структура

| Экспорт | Назначение |
|--------|------------|
| `Sidemenu` | Боковое меню приложения. |
| `NavigationMenu`, `NavigationMenuItem`, `NavigationMenuContext`, `useNavigationMenuContext`, `getNavigationMenuItemDisplayTitle` | Древовидная навигация (не путать с `Menu`). |
| `Menu`, `MenuItem` | Меню действий `role="menu"`. |
| `FloatingMenu`, `FloatingMenuGroup`, `FloatingMenuGroupItem`, `FloatingMenuDivider`, `FloatingMenuDragHandle` | Плавающая панель инструментов. |
| `FloatingMenuPlacement`, `FloatingMenuGroupVariant`, `FloatingMenuDropdownTrigger`, `FloatingMenuDragSource` | Типы/константы для FloatingMenu. |
| `Tabs`, `TabItem`, `TabsVariant` | Вкладки: **pill**, **minimal**, **line**, **underline**; проп **filledSegmentTriggers** для заливки текстовых сегментов. |
| `Breadcrumb` | «Хлебные крошки». |
| `Stepper` | Пошаговый процесс (`compact` / `linear`). |
| `Pagination` | Нумерация страниц вне таблицы. |
| `Accordion` | Раскрывающиеся секции. |

Выпадающие панели **`Dropdown`** описаны в разделе «Поверхности»; они используются в календаре, фильтрах таблицы и т.д.

```tsx

  Sidemenu,
  NavigationMenu,
  NavigationMenuItem,
  Menu,
  MenuItem,
  FloatingMenu,
  FloatingMenuGroup,
  FloatingMenuGroupItem,
  FloatingMenuDivider,
  FloatingMenuDragHandle,
  Tabs,
  TabItem,
  Breadcrumb,
  Stepper,
  Pagination,
  Accordion,
} from '@velkinvv/plainerv';
```

## Таблицы и DataGrid

| Экспорт | Назначение |
|--------|------------|
| `TableContainer`, `TableContainerScroll` | Обычная таблица: контейнер и скролл (`scrollAreaMaxHeight`, липкая шапка). |
| `Table`, `TableHead`, `TableBody`, `TableFooter`, `TableRow`, `TableCell` | Структура таблицы. |
| `TableCellFormatted` | Ячейка с декларативным `format` без DataGrid. |
| `TablePagination` | Пагинация под таблицей (размер страницы и т.д.). |
| `TableSortLabel`, `TableSortChevronIcon` | Сортировка в шапке. |
| `getTableTotalPages`, `clampTablePageZeroBased`, `toggleTableSortDirection`, `getSortChevronTones`, `getTableSortChevronColor`, `parseTablePageJumpInput` | Утилиты таблицы. |
| `DataGrid` | Таблица с колонками, пагинацией, сортировкой, раскрытием строк, drag колонок/строк; у колонки — `format: TableCellFormat` или `render`; проп `excelExport` — выгрузка в `.xls`. |
| `formatTableCellValue`, `formatTableCellExportCellValue`, `TABLE_CELL_MASK_*` | Форматирование ячеек для UI и Excel — реэкспорт из handlers. |
| Выгрузка DataGrid в Excel | `DataGridExcelExportButton`, `buildDataGridExcelExportSpreadsheet`, `downloadDataGridExcelSpreadsheetFile`, `resolveDataGridExportCellValue`, `convertDataGridColumnsToExportColumns`, `validateDataGridExcelExportPageRange`, … |
| Вспомогательные функции DataGrid | `applyDataGridColDragGhostPreview`, `applyDataGridRowDragGhostPreview`, `sliceRowsForPagination`, `getDataGridCellValue`, `reorderByIndex`, `toIdSet`, `resolveDataGridExpandedRowDataStatus`, `normalizeDataGridSortModel`, `resolveNextDataGridSortModel`, `getDataGridSortCriterionIndexForField`, константы drag-preview и переходов. |
| `ColumnFilterPanel` | Панель фильтра колонки (слот под поля, Применить/Очистить). |

Также экспортируются типы: `TableContainerProps`, `TableProps`, `DataGridProps`, `DataGridColumn`, `DataGridExcelExportConfig`, `DataGridExcelExportCellStyle`, `DataGridExcelExportCellValue`, … и CSS-переменная/хелпер заголовка (см. `CHANGELOG` и сторис **Table** / **DataGrid**).

```tsx
import {
  TableContainer,
  TableContainerScroll,
  Table,
  TableHead,
  TableBody,
  TableRow,
  TableCell,
  TablePagination,
  TableSortLabel,
  DataGrid,
  ColumnFilterPanel,
} from '@velkinvv/plainerv';
```

## Обратная связь

| Экспорт | Назначение |
|--------|------------|
| `Tooltip` | Краткая подсказка по ховеру/фокусу. |
| `Hint`, `HintPosition`, `HintVariant` | Расширенная подсказка рядом с контентом. |
| `Toast`, `ToastProvider`, `ToastAppearance` | Стек toast-уведомлений. |
| `Snackbar`, `SnackbarProvider` | Полосы snackbar. |

Провайдеры и хуки: **`useToast`**, **`useSnackbar`** (см. также реэкспорт типов `ToastType`, `ShowToastOptions`, `SnackbarPlacement`, …).

```tsx
import {
  Tooltip,
  Hint,
  Toast,
  ToastProvider,
  Snackbar,
  SnackbarProvider,
  useToast,
  useSnackbar,
} from '@velkinvv/plainerv';
```

## Обработчики и утилиты (реэкспорт)

Из `@velkinvv/plainerv` также доступны модули **handlers** (например `dateHandlers`, `timeHandlers`, `linkHandlers`, `tableCellFormat`, `formatTableCellValue`, `tableSelectionHandlers`, `dropdownSearchMatchHandlers`, motion/navigation helpers и др.) — см. `src/handlers/index.ts` и Storybook-сторис в каталоге **Handlers**.

Для styled-components в своих обёртках:

- **`createStyledShouldForwardProp`** — `shouldForwardProp` с фильтром `$…` и кастомных пропов (не настройка Vite; см. [Vite](/docs/web/v_0.3.1/vite));
- **`plainervVite`** — из `@velkinvv/plainerv/vite`, плагин для Vite;
- **`omitMotionConflictingDomHandlers`** — перед spread на `motion.button` / `motion.a`.

# DateInput + Calendar

Эти компоненты покрывают сценарии выбора даты как в простых формах, так и в планировщиках.

## DateInput

```tsx
import { DateInput } from '@velkinvv/plainerv';

type DeadlineDateInputProps = {
  deadlineDateValue?: string | { start: string; end: string };
  onDeadlineDateChange: (
    nextDeadlineDateValue: string | { start: string; end: string },
  ) => void;
};

export function DeadlineDateInput({
  deadlineDateValue,
  onDeadlineDateChange,
}: DeadlineDateInputProps) {
  return (
    <DateInput
      label="Дедлайн"
      value={deadlineDateValue}
      onChange={onDeadlineDateChange}
      placeholder="Выберите дату"
    />
  );
}
```

## Основные входные параметры

### DateInput

- `value?: string | DateTimeRange` — выбранная дата или диапазон;
- `onChange?: (nextDeadlineDateValue: string | DateTimeRange) => void` — обработчик изменения даты/диапазона;
- `precision?: 'day' | 'month' | 'year' | 'monthYear' | 'week'` — точность: полный день (календарь, `YYYY-MM-DD`), месяц / год без сетки дней (`YYYY-MM` / `YYYY`) или неделя месяца (`YYYY-MM-W2`);
- `weekOfMonthMode?: 'calendar' | 'chunks'` — нумерация недель при `precision="week"`: с понедельника или семёрки 1–7, 8–14, …;
- `format?: string` — отображение в поле (`MM.YYYY`, `MMMM YYYY`, `YYYY`, `W.MM.YYYY`); на каноническую строку `onChange` не влияет;
- `label?: string` — подпись поля (по умолчанию как у Input: токены `typography.label`, цвет `colors.text`);
- `labelVariant?: 'field' | 'floating'` — `field` (default) или прежний floating-лейбл; `padding-top: 10px` на корне только в `floating` при наличии `label` / `additionalLabel`;
- `placeholder?: string` — текст-подсказка в пустом состоянии.

## Calendar

```tsx
import { Calendar } from '@velkinvv/plainerv';

type ReleaseCalendarProps = {
  selectedReleaseDate?: Date;
  onReleaseDateSelect: (nextReleaseDateValue: Date) => void;
};

export function ReleaseCalendar({
  selectedReleaseDate,
  onReleaseDateSelect,
}: ReleaseCalendarProps) {
  return (
    <Calendar
      value={selectedReleaseDate}
      onChange={onReleaseDateSelect}
      locale="ru"
      weekStartsOn={1}
      minDate={new Date('2026-01-01')}
      maxDate={new Date('2026-12-31')}
    />
  );
}
```

### Calendar

- `value?: Date | null` — выбранная дата;
- `onChange?: (nextReleaseDateValue: Date) => void` — обработчик выбора даты;
- `locale?: string` — локаль отображения названий;
- `weekStartsOn?: 0 | 1` — день начала недели;
- `minDate?: Date` — минимально доступная дата;
- `maxDate?: Date` — максимально доступная дата.

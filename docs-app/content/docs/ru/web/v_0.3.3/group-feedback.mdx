# Feedback

Группа компонентов для уведомлений и сообщений о состоянии действий.

**Компоненты:** `Tooltip`, `Hint`, `Toast`, `ToastProvider`, `Snackbar`, `SnackbarProvider`, `Pulse` (статусная точка с волной).

**Хуки:** `useToast`, `useSnackbar` (провайдеры обязательны в дереве приложения).

Справочник: [компоненты — обратная связь](/docs/web/v_0.3.3/components-catalog). Гайды: [Toast + Snackbar](/docs/web/v_0.3.3/components-toast-snackbar), [SegmentedControl + Pulse](/docs/web/v_0.3.3/components-segmented-pulse).

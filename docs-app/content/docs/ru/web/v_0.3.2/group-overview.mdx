# Overview

Раздел для стартовых и обзорных материалов версии **v0.3.2**.

**Полный перечень компонентов, хуков и реэкспортов** пакета: [Справочник компонентов](/docs/web/v_0.3.2/components-catalog).

## Что нового в 0.3.2

- Подготовка релиза **0.3.2** (ветка `v_0.3.2`).
- Всплывающие панели (DateInput, Dropdown, Select, Popover, FloatingMenu) при первом открытии появляются сразу под якорем, без вылета из левого верхнего угла.

См. [Changelog](/docs/web/v_0.3.2/changelog), [README](/docs/web/v_0.3.2/readme).

## Что нового в 0.3.1

- Подготовка релиза **0.3.1** (ветка `v_0.3.1`).
- **DateInput / TimeInput / DateTimeInput:** дефолтный `label` как у Input; `labelVariant="floating"` — прежний визуал. `padding-top: 10px` только в floating при наличии лейбла.

См. [Changelog](/docs/web/v_0.3.2/changelog), [README](/docs/web/v_0.3.2/readme).

- **Badge:** motion-анимация контента; **ValueMotion** — пульсирующее значение.
- **Inputs:** анимированный счётчик символов.

См. [Changelog](/docs/web/v_0.2.6/changelog), [README](/docs/web/v_0.2.6/readme).

## Что нового в 0.2.5

## Что нового в 0.2.1

- **Input:** единая раскладка `InputFieldShell`; **DataGrid / Table:** исправления горизонтального скролла и `headerToolbar`.

## Что нового в 0.2.0

- **SliderInput — `range`:** диапазон «от / до», типы **`SliderInputSingleProps`** / **`SliderInputRangeProps`**. [SliderInput](/docs/web/v_0.3.2/components-slider-input).
- **DataGrid — выгрузка в Excel** (`.xls`, SpreadsheetML): проп **`excelExport`**, модалка диапазона страниц, цвета и подписи из **`format`** / **`render`**.
- **DataGrid / Table:** **`columns[].format`**, split-layout скролла, **`horizontalScroll`** по умолчанию, пустое состояние, **refetch** и сброс фильтров.
- **Tabs** (**breaking**): варианты **pill** / **minimal** / **line** / **underline**, **filledSegmentTriggers**; объединение с **Switcher**.
- **Modal:** иконки статуса в шапке.

См. [SliderInput](/docs/web/v_0.3.2/components-slider-input), [Table + DataGrid](/docs/web/v_0.3.2/components-table-datagrid), [Tabs + Pagination](/docs/web/v_0.3.2/components-tabs-pagination), [Changelog](/docs/web/v_0.3.2/changelog), [README](/docs/web/v_0.3.2/readme).

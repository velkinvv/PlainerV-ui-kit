# Quick Start

Эта страница — короткий старт для `v0.1.3`, чтобы быстро подключить библиотеку и получить рабочий UI.

## 1) Установка

```bash
npm i @velkinvv/plainerv
```

## 2) Подключение темы в корне приложения

```tsx
import { ThemeProvider } from '@velkinvv/plainerv';

type ApplicationRootProps = {
  children: React.ReactNode;
};

export function ApplicationRoot({ children }: ApplicationRootProps) {
  return <ThemeProvider>{children}</ThemeProvider>;
}
```

## 3) Первый рабочий экран

```tsx
import { Button, Card, Input } from '@velkinvv/plainerv';

export function QuickStartDemo() {
  return (
    <Card>
      <Input label="Email" placeholder="team@plainerv.dev" />
      <Button variant="primary">Сохранить</Button>
    </Card>
  );
}
```

## Входные параметры ключевых компонентов

- `ThemeProvider.children: React.ReactNode` — дерево приложения внутри темы;
- `Input.label?: React.ReactNode` — подпись поля;
- `Input.placeholder?: string` — текст-подсказка в пустом состоянии;
- `Button.variant?: ButtonVariant` — визуальный вариант кнопки;
- `Button.children?: React.ReactNode` — содержимое кнопки.

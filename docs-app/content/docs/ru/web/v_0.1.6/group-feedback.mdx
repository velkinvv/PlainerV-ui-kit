# Feedback

Группа компонентов для уведомлений и сообщений о состоянии действий.

**Компоненты:** `Tooltip`, `Hint`, `Toast`, `ToastProvider`, `Snackbar`, `SnackbarProvider`.

**Хуки:** `useToast`, `useSnackbar` (провайдеры обязательны в дереве приложения).

Справочник: [компоненты — обратная связь](/docs/web/v_0.1.6/components-catalog). Гайд: [Toast + Snackbar](/docs/web/v_0.1.6/components-toast-snackbar).

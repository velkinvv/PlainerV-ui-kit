# Overview

Раздел для стартовых и обзорных материалов версии **v0.1.6**.

**Полный перечень компонентов, хуков и реэкспортов** пакета: [Справочник компонентов](/docs/web/v_0.1.6/components-catalog).

## Что нового в 0.1.6

- **Peer dependencies** для `react`, `react-dom`, `styled-components`, `framer-motion`; транзитивно с китом — `clsx`, `dayjs`.
- Плагин Vite: **`plainervVite()`** из `@velkinvv/plainerv/vite` (dedupe, `optimizeDeps.exclude` кита).
- Сборка Rollup без предупреждений TypeScript (в т.ч. React 19, `NullableRefObject`).
- Экспорт **`createStyledShouldForwardProp`** и **`omitMotionConflictingDomHandlers`**.
- **Tabs:** проп **`items`**, варианты **pill** / **minimal** / **line** / **underline** — см. [Tabs + Pagination](/docs/web/v_0.1.6/components-tabs-pagination).

См. [Vite](/docs/web/v_0.1.6/vite), [Changelog](/docs/web/v_0.1.6/changelog), [README](/docs/web/v_0.1.6/readme).

# Data Display

Группа компонентов для табличного и структурированного отображения данных.

**Компоненты:** `Badge`, `Tag`, `Pill`, `Chip`, `Chips`, `List`, `Avatar`, `AvatarGroup`, `Progress`, `Spinner`, `Pulse`, `Skeleton`, `Divider`, `Slider`, `RangeSlider`, `Calendar`, `DateRollerPicker`, `Icon`, `ThemeToggle`.

**Таблицы:** `TableContainer`, `TableContainerScroll`, `Table`, `TableHead`, `TableBody`, `TableFooter`, `TableRow`, `TableCell`, `TablePagination`, `TableSortLabel`, `TableSortChevronIcon`, утилиты пагинации/сортировки, `DataGrid` (в т.ч. выгрузка в Excel через `excelExport`), `ColumnFilterPanel`.

Полный список импортов: [Справочник компонентов](/docs/web/v_0.2.7/components-catalog). Руководства: [Chip + List](/docs/web/v_0.2.7/components-chip-list), [Table + DataGrid](/docs/web/v_0.2.7/components-table-datagrid).

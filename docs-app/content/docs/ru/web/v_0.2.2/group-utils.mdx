# Utils

Группа **документов** про вспомогательные темы и утилиты пакета.

**Из пакета:** хуки (`useModal`, `useDebounce`, `useWindowSize`, `useIsDesktop`, …), **handlers** (дата/время, ссылки, таблица, motion и др.), типы и CSS-переменные — всё в [Справочнике компонентов](/docs/web/v_0.2.2/components-catalog).

Темизация: [Theming](/docs/web/v_0.2.2/theming) (`ThemeProvider`, `ThemeToggle`, `ThemeSelector`, `defineThemeCatalog`). Быстрый старт: [Quick Start](/docs/web/v_0.2.2/quick-start).

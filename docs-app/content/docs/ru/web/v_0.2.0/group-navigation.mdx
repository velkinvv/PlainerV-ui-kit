# Navigation

Группа компонентов для навигации по разделам и контенту.

**Экспорты:** `Sidemenu`, `NavigationMenu`, `NavigationMenuItem` (и контекст/хелперы), `Menu`, `MenuItem`, `FloatingMenu` и субкомпоненты, `Tabs`, `TabItem`, `Breadcrumb`, `Stepper`, `Pagination`, `Accordion`, `Dropdown` (меню/панели).

Справочник: [Навигация](/docs/web/v_0.2.0/components-catalog). Гайды: [Tabs + Pagination](/docs/web/v_0.2.0/components-tabs-pagination), [FloatingMenu](/docs/web/v_0.2.0/components-floating-menu).

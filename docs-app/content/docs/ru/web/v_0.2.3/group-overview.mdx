# Overview

Раздел для стартовых и обзорных материалов версии **v0.2.3**.

**Полный перечень компонентов, хуков и реэкспортов** пакета: [Справочник компонентов](/docs/web/v_0.2.3/components-catalog).

## Что нового в 0.2.3

- **Glass-темы:** `glassLight` и `glassDark` с vibrancy на базе blur-токенов; `surfaceMaterial`, mesh-gradient фон.
- **Storybook:** поддержка glass-тем в toolbar и Docs, обновлён canvas.
- **Windows / dev:** `cross-env` для `npm start`, optional `@rollup/rollup-win32-x64-msvc`.

См. [Changelog](/docs/web/v_0.2.3/changelog), [README](/docs/web/v_0.2.3/readme).

## Что нового в 0.2.2

- **Storybook:** **Theme Showcase**, интеграция с UI-kit, доработка тёмной темы.
- **Тесты и качество:** Jest для **npm workspaces**, исправления ESLint и unit-тестов.

См. [Changelog](/docs/web/v_0.2.3/changelog), [README](/docs/web/v_0.2.3/readme).

## Что нового в 0.2.1

- **Темизация:** каталог тем (`defineThemeCatalog`, `themeMode`, `ThemeSelector`), `ThemeColorScheme` / `ThemeMode`, `mergeTheme`, `useMergeTheme` — [Theming](/docs/web/v_0.2.3/theming).
- **Input:** единая раскладка `InputFieldShell`; **DataGrid / Table:** исправления горизонтального скролла и `headerToolbar`.

## Что нового в 0.2.0

- **SliderInput — `range`:** диапазон «от / до», типы **`SliderInputSingleProps`** / **`SliderInputRangeProps`**. [SliderInput](/docs/web/v_0.2.3/components-slider-input).
- **DataGrid — выгрузка в Excel** (`.xls`, SpreadsheetML): проп **`excelExport`**, модалка диапазона страниц, цвета и подписи из **`format`** / **`render`**.
- **DataGrid / Table:** **`columns[].format`**, split-layout скролла, **`horizontalScroll`** по умолчанию, пустое состояние, **refetch** и сброс фильтров.
- **Tabs** (**breaking**): варианты **pill** / **minimal** / **line** / **underline**, **filledSegmentTriggers**; объединение с **Switcher**.
- **Modal:** иконки статуса в шапке.

См. [SliderInput](/docs/web/v_0.2.3/components-slider-input), [Table + DataGrid](/docs/web/v_0.2.3/components-table-datagrid), [Tabs + Pagination](/docs/web/v_0.2.3/components-tabs-pagination), [Changelog](/docs/web/v_0.2.3/changelog), [README](/docs/web/v_0.2.3/readme).

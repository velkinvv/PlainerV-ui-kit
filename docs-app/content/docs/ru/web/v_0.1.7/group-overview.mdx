# Overview

Раздел для стартовых и обзорных материалов версии **v0.1.7**.

**Полный перечень компонентов, хуков и реэкспортов** пакета: [Справочник компонентов](/docs/web/v_0.1.7/components-catalog).

## Что нового в 0.1.7

- **npm:** README в tarball и на странице пакета.
- **Peer dependencies** для `react`, `react-dom`, `styled-components`, `framer-motion`; транзитивно — `clsx`, `dayjs`.
- Плагин Vite: **`plainervVite()`** из `@velkinvv/plainerv/vite`.
- Сборка Rollup без предупреждений TypeScript (React 19, `NullableRefObject`).
- **Tabs:** проп **`items`**, варианты **pill** / **minimal** / **line** / **underline** — см. [Tabs + Pagination](/docs/web/v_0.1.7/components-tabs-pagination).

См. [Vite](/docs/web/v_0.1.7/vite), [Changelog](/docs/web/v_0.1.7/changelog), [README](/docs/web/v_0.1.7/readme).

# Data Display

Группа компонентов для табличного и структурированного отображения данных.

**Компоненты:** `Badge`, `Tag`, `Pill`, `Avatar`, `AvatarGroup`, `Progress`, `Spinner`, `Skeleton`, `Divider`, `Slider`, `RangeSlider`, `Calendar`, `DateRollerPicker`, `Icon`, `ThemeToggle`.

**Таблицы:** `TableContainer`, `TableContainerScroll`, `Table`, `TableHead`, `TableBody`, `TableFooter`, `TableRow`, `TableCell`, `TablePagination`, `TableSortLabel`, `TableSortChevronIcon`, утилиты пагинации/сортировки, `DataGrid`, `ColumnFilterPanel`.

Полный список импортов: [Справочник компонентов](/docs/web/v_0.1.7/components-catalog). Руководства: [Table + DataGrid](/docs/web/v_0.1.7/components-table-datagrid).

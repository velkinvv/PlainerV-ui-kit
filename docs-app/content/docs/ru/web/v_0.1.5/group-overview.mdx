# Overview

Раздел для стартовых и обзорных материалов версии **v0.1.5**.

**Полный перечень компонентов, хуков и реэкспортов** пакета: [Справочник компонентов](/docs/web/v_0.1.5/components-catalog).

## Что нового в 0.1.5

- Сборка Rollup без предупреждений TypeScript (`TS2769`, `TS7006`).
- Экспорт **`createStyledShouldForwardProp`** и **`omitMotionConflictingDomHandlers`** (styled-components + Framer Motion).
- Поддержка React 19 в **TabItem** и типизация обработчиков в полях ввода.
- Стабильный путь модуля таблиц: `src/components/ui/table` (casing на Windows).

См. [Changelog](/docs/web/v_0.1.5/changelog) и [README](/docs/web/v_0.1.5/readme).

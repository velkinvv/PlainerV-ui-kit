# Theming

Тема управляется через `ThemeProvider` и `useTheme`.

## Пример

```tsx
import { Button, useTheme } from '@velkinvv/plainerv';

export function ThemeControls() {
  const { mode, toggle } = useTheme();

  return (
    <section>
      <p>Текущий режим: {mode}</p>
      <Button variant="secondary" onClick={toggle}>
        Переключить тему
      </Button>
    </section>
  );
}
```

## Входные параметры и значения

- `ThemeProvider.children: React.ReactNode` — дерево компонентов внутри темы;
- `useTheme().mode` — текущий режим;
- `useTheme().toggle()` — переключение режима.

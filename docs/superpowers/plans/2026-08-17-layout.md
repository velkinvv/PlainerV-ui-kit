# Layout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить семейство `Layout` / `Layout.Header` / `Layout.Sidebar` / `Layout.Content` / `Layout.Footer`: каркас страницы на flex, collapse и брейкпоинт сайдбара, overlay, sticky, два режима скролла.

**Architecture:** Чистые хелперы считают направление корня, ширину, порог брейкпоинта, overlay-gutter и поворот шеврона. Корень через контекст регистрирует Sidebar и прокидывает `scrollMode`. Визуал только из темы. Sidemenu в сайдбар не вшивать.

**Tech Stack:** React 19, TypeScript, styled-components 6, Jest + Testing Library, Storybook 9.

Breakpoint:
```ts
const breakpointQuery = breakpoint != null ? getLayoutSidebarBreakpointMediaQuery(breakpoint) : '';
const isBelow = useMediaQuery(breakpointQuery || '(min-width: 0px)');
```
Не вызывать `useMediaQuery` с пустой строкой: если нет breakpoint — не подписываться. Либо всегда вызывать с `'all'` и игнорировать. Предпочтительно:

```ts
const isBelowBreakpoint = useMediaQuery(
  breakpoint != null ? getLayoutSidebarBreakpointMediaQuery(breakpoint) : '(min-width: 0px)',

```

`(min-width: 0px)` почти всегда true — **нельзя**. Если `breakpoint == null`, не использовать результат. Паттерн:

```ts
const mediaMatches = useMediaQuery(

const isBelow = breakpoint != null && mediaMatches;
```
